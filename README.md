# dynamic-ui
POC for dynamic UI + design system in storybook

## Try it now

Before the main workspace exists (milestone M2), a thin slice runs from the
M1 spike:

```sh
cd spikes/001-renderer
pnpm install
pnpm storybook   # then open http://localhost:6006
```

- Running in a VirtualBox VM on Windows: [docs/dev-env/virtualbox-debian.md](docs/dev-env/virtualbox-debian.md)
